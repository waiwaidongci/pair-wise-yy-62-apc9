# pair-wise-yy-62 多用途船舶配载方案校核与航次审阅平台

支持集装箱、散货和重大件配载，提供三维货位查看、二维剖面、拖拽换位、重心与稳性计算、危险品隔离、绑扎冲突、方案对比和可打印配载图。

## 技术栈

React、Mantine、Redux Toolkit、React Router、RTK Query、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62062`。方案草稿保存在浏览器本地状态。

```bash
npm run build
```

## 配载快照（改港 / 双码头 / 断网）

`src/snapshot/` 下三个职责互不耦合：

- `adjudication.ts` **快照判定**：按提单号识别货物；货位/卸货港/绑扎变化时只重算受影响港口的卸货顺序、危险品隔离、稳性裕度与绑扎复核（港口指纹保证其他港口结论继续有效）；输出锁定/打印闸门，旧靠港顺序版本的快照不得放行，重算未完成不能锁定或打印。
- `gateway.ts` **请求入口**：码头导入的唯一入口，按 `batchId` 幂等（重复导入沿用第一次结果），保存失败时原批次留在队列待重试，成功后才写入快照。
- `merge.ts` **离线合并**：两个终端断网期间的修改在恢复后按提单号三路合并；相同修改采用一份，单边修改直接采用，货位不同则保留两份待选，与锁定版冲突时锁定版作为不可覆盖的候选同时保留。
- `snapshotSlice.ts`：快照链（工作 / 改港 / 锁定副本）、异步重算令牌、批次队列与离线状态；`store.ts` 的桥接中间件把配载页编辑提交给快照、把权威货位回灌总览 / 对比 / 打印。

操作入口在「配载快照」页（`/snapshot`），原有总览、配载、对比、打印页面继续可用，其锁定与打印按钮同样受快照闸门约束。
